# 🚀 Gestor e Criador de Projetos

Um sistema intuitivo e eficiente desenvolvido para ajudar na organização, planejamento e criação de novos projetos, permitindo gerenciar tarefas e acompanhar o progresso de forma simples.

---

## 📋 Sobre o Projeto

Este repositório serve como a base central de documentação e desenvolvimento do **Gestor e Criador de Projetos**.

O objetivo principal é otimizar o fluxo de trabalho, permitindo estruturar ideias, definir etapas, gerenciar tarefas e manter o controle completo sobre o ciclo de vida de qualquer projeto.

---

## ✨ Funcionalidades Principais

- ✅ Criação de projetos
- ✅ Definição de objetivos e metas
- ✅ Gestão de tarefas
- ✅ Acompanhamento de progresso
- ✅ Interface simples e intuitiva
- ✅ Organização eficiente das atividades

## 🚀 Como Executar

### 1. Clonar o repositório

```bash
git clone https://github.com/Maristelacosta/Plano-Projeto---Gestor-e-Criador-de-Projetos.git
```

### 2. Acessar a pasta

```bash
cd Plano-Projeto---Gestor-e-Criador-de-Projetos
```

### 3. Abrir o projeto

Abra o arquivo `index.html` em qualquer navegador.
