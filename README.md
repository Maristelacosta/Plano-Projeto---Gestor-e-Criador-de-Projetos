# 🚀 Plano de Projeto - Gestor e Criador de Projetos

Um sistema intuitivo e eficiente desenvolvido para ajudar na organização, planeamento e criação de novos projetos, permitindo gerir tarefas e acompanhar o progresso de forma simples.

---

## 📋 Sobre o Projeto

Este repositório serve como a base central de documentação e desenvolvimento do **Gestor de Projetos**. O objetivo principal é otimizar o fluxo de trabalho, permitindo estruturar ideias, definir etapas e manter o controlo total sobre o ciclo de vida de qualquer projeto.

---

## ✨ Funcionalidades Principais

- **Criação de Projetos:** Estruturação rápida de novas ideias e respetivos objetivos.
- **Gestão de Tarefas:** Organização de etapas e acompanhamento de entregas.
- **Interface Limpa e Intuitiva:** Focada na produtividade e facilidade de uso.
